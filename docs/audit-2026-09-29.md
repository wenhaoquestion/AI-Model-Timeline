- 精确日期核验失败、官方日期冲突、只有目录名称而无首发依据的项保留 `unverified`。不能把本轮完成说成所有日期均已证实

## 独立复核发现并修正

- **可见性**：GPT-6 Sol、GPT-6 Astra 和 GPT-6.1 Sol 原本均存在；短时长色块隐藏名称、搜索不滚动到对应纵向轨道造成难找。现保持真实色块时长，名称单独显示并分行；搜索忽略常见空格/连字符，支持原合并名称别名并定位结果
- **历史核验缺口**：原补充审计漏掉 172 条中国公司早期无来源记录。本轮逐条赋予证据结论，日期冲突或无法核实项显式待核验。详见两个历史复核文件
- **发布阶段**：恢复 Qwen-Image-3.0 的模型公告日期，另列后续 API 上线；HY 2.0、Wan 等亦将地区/服务上线与更晚公告分开
- **模型遗漏**：补充与 Eleven v4 同日发布的 Eleven v4 Turbo，并保留独立低延迟轨道。来源：[Eleven v4 发布文](https://elevenlabs.io/blog/eleven-v4)
- **错误结束日期**：移除 o3-pro 的 2025-08-07、GPT-5.3-Codex 的 2026-03-05、PaLM 2 的 2023-12-06。这些是产品接替或更新事件，不能当成该模型 API/权重统一退役
- **撤回的退役安排**：DeepSeek 官方已明确 V4 Pro 在 2026-09-14 后继续 API 服务，移除先前计划产生的结束日期。来源：[DeepSeek 日志](https://api-docs.deepseek.com/updates/)
- **诚实状态**：GLM-5.3、Hy Image 3.5 preview、Step 5 Preview 的具体日期仍缺足够直接依据，保持待核验，不能仅凭当前目录或“1w”等相对日期认定某天
- **校验器**：修复空数组、空对象、0、false 被当成未知日期放行并在前端消失的问题。未知日只接受 null/缺省且要求官方身份来源及待核验标记

## 回归检查

- `python3 build.py --check`：数据结构、日期、来源 HTTPS、重名、截止日及未知日期约束
- `python3 -m unittest discover -s tests -v`：16 项校验器与历史名称保留回归测试
- `node tests/test_timeline.js`：版本接替、同日并行、未知日期目录、移动/桌面宽度标签防碰撞、搜索别名、SVG/PNG 不确定性标记与脚本语法
- 本地 DOM 执行测试：375/1188 宽度配置下搜索、重置、无结果、未知日目录、零日 GPT-6.1 Sol 的 SVG 标签与导出记录数；此项使用 DOM/测量替身，不冒充真实浏览器截图
- 独立计算核对：579 个基线名称均在当前名称/别名集合，所有导出场景坐标有效，生成的 `dist/index.html` 与模板/数据一致
- 浏览器限制：本地 headless Chromium 启动被执行环境的 socket 权限阻止，云浏览器不接受 localhost/file 预览；实际线上交互在 GitHub Pages 发布后另外核对
- 全量 PNG 受浏览器画布上限需缩放，文字可能很小；SVG 保留矢量全文，建议全量导出用 SVG
